## 2026-10-04: ROOT CAUSE of the onboarding failure found and fixed (migration 20261006)
- **Cause:** `authenticated` and `anon` held **no table privileges** (only TRUNCATE/REFERENCES/TRIGGER) on any app table in the live project. The migrations assumed Supabase's default privileges; this project doesn't have them, and the local test stub (`alter default privileges ... grant all`) hid it. Postgres refused the `profiles` upsert before RLS ran. The same gap would have broken saving, status updates, feedback, anonymous landing-page analytics events and admin writes. Found by inspecting `pg_policy`/`role_table_grants` in the Supabase SQL editor (read-only).
- **Fix:** `supabase/migrations/20261006000000_explicit_table_grants.sql` (minimum grants matching each RLS policy; `cron_secret`/`reminder_log` stay ungranted). Applied to production by running the same GRANT statements in the SQL editor (outside migration history, as before). Local test stub no longer grants default table privileges, so the DB tests now fail without the migration; verifier gained grant checks.
- **Live proof (authenticated smoke, HTTP mode, alias `+oosmoke`):** magic link -> onboarding POST 303 -> `/dashboard?welcome=1`; dashboard deterministic and CSP-nonced; non-admin bounced from all admin routes; profile edit persisted; **disposable account deleted** (`/?deleted=1`). The orphaned smoke accounts from attempts #1-#3 were the same user; it no longer exists.
- **Harness bugs fixed:** chunk discovery missed Next 16's `/_next/static/immutable/chunks/` path (so server actions could not be found and cleanup failed); the post-delete stale-cookie check did not accept a streamed `200 + meta refresh` redirect. Both covered by tests. The stale-cookie check was fixed after the account was gone, so it has not been re-run live.
- **NOT verified live (external blocker):** the card-dependent steps (detail page, save, apply-link click, status, feedback, analytics rows, admin allow-path) because production has **0 verified opportunities**. The only real record (FCYLP) is an unverified draft; its two evidence quotes (deadline Nov 8 2026, $1,000 pay) were re-confirmed verbatim on https://www.fairfaxcounty.gov/budget/youth-leadership on 2026-10-04, but verifying requires an admin and **no admin exists** (`public.admins` is empty). Granting admin was declined by the session's permission guard, so it is left for the account owner (`supabase/make-admin.sql`, then Save & verify in /admin).
